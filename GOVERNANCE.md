# Project Governance

## Purpose

Talent Prism is maintained as an open-source reference implementation by **Dev Tripathy AI Systems**.

The goal of the project is to share practical engineering knowledge, architectural patterns, and implementation techniques for AI-assisted applicant evaluation systems.

---

# Project Maintainer

The project is currently maintained by:

**Dev Tripathy AI Systems**

The maintainer is responsible for:

- Repository direction
- Architecture decisions
- Reviewing pull requests
- Managing releases
- Documentation
- Security updates

---

# Decision Making

Project decisions are guided by the following principles:

- Simplicity
- Maintainability
- Security
- Extensibility
- Clear documentation
- Vendor-agnostic architecture

When evaluating contributions, preference is given to changes that improve the reference implementation without significantly increasing complexity.

---

# Contributions

Community contributions are welcome.

All contributions are reviewed before being merged.

Submission of a pull request does not guarantee acceptance.

Maintainers may request modifications to ensure consistency with the project's architecture and goals.

---

# Scope

Talent Prism intentionally focuses on demonstrating:

- Workflow automation
- AI integration
- Secure media processing
- Configurable architecture
- Frontend integration

Features outside the repository's intended scope may be declined even if technically correct.

---

# Releases

Official releases are published by the project maintainer.

Community forks are encouraged but are not considered official releases of Talent Prism.

---

# Community

We welcome:

- Documentation improvements
- Bug fixes
- Security improvements
- Architecture discussions
- Integration examples
- Educational contributions

Constructive feedback and respectful collaboration are encouraged.
