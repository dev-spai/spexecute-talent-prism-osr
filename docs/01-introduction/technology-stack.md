# Technologies Used

Talent Prism combines modern cloud services, workflow automation, AI, and open-source technologies to create a modular applicant evaluation platform.

The technologies selected for this reference implementation emphasize flexibility, extensibility, and ease of integration rather than vendor lock-in.

| Technology | Purpose |
| --- | --- |
| **n8n** | Workflow orchestration and automation |
| **Supabase** | Structured applicant data storage |
| **Cloudflare R2** | Private object storage for applicant media |
| **Cloudflare Workers** | Secure generation of time-limited signed URLs |
| **Google Gemini** | AI-powered photo quality and candidate evaluation |
| **Airtable** | Organization-specific configuration management |
| **HTTP Webhooks** | Applicant intake and workflow triggers |
| **JSON** | Organization configuration and structured data exchange |

---

## Workflow Automation

**n8n**

Talent Prism uses n8n as the workflow orchestration engine responsible for coordinating the complete applicant lifecycle.

Example responsibilities include:

- Applicant intake
- Request validation
- Consent verification
- Duplicate detection
- Media processing
- AI evaluation
- Workflow chaining
- Scheduled maintenance workflows

---

## Database

**Supabase**

Supabase stores structured applicant records, workflow metadata, evaluation results, and processing status.

It serves as the central source of truth for the applicant lifecycle while remaining independent of frontend implementations.

---

## Object Storage

**Cloudflare R2**

Applicant photographs and supporting media are stored securely in Cloudflare R2.

Private media is never exposed directly. Instead, authorized applications access objects using temporary signed URLs generated by a Cloudflare Worker.

---

## AI Evaluation

**Google Gemini**

Google Gemini performs AI-assisted evaluation throughout the applicant processing pipeline.

Depending on workflow configuration, AI evaluation may include:

- Photo quality assessment
- Structural analysis
- Category recommendations
- Organization-specific scoring
- Confidence metrics

The prompts, scoring criteria, and evaluation methodology are configurable for each organization.

---

## Organization Configuration

**Airtable**

Rather than embedding organization-specific settings in workflows, Talent Prism stores configuration externally.

This enables organizations to modify:

- Qualification thresholds
- Evaluation prompts
- Categories
- Submission requirements
- Supported markets
- Organization metadata

without changing workflow logic.

---

## Secure Media Access

**Cloudflare Workers**

A lightweight Cloudflare Worker generates AWS Signature Version 4 compatible presigned URLs for Cloudflare R2.

This approach allows organizations to securely serve private applicant media without exposing storage buckets publicly.

---

## Integration

Talent Prism communicates using standard HTTP requests and structured JSON payloads, making it compatible with virtually any frontend framework, backend service, or enterprise platform.

Common integration targets include:

- React
- Next.js
- Vue
- Angular
- Flutter
- Bubble
- Retool
- WordPress
- Existing Talent Management Systems
- Internal APIs
